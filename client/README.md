# MARCH ROLE PLAY — клиентские файлы

Лаунчер копирует **уже установленную пользователем GTA San Andreas** в выбранную отдельную папку `GTA San Andreas/`, не меняя оригинал. GTA SA и MTA не входят в наш дистрибутив.

После полной установки режим «Обновить файлы» получает `client/manifest.json` с основной ветки репозитория и скачивает **только** указанные там файлы внутрь `MARCH Assets/`. Пока список `files` пустой — моделей для скачивания ещё нет.

## Добавление модели

Загрузить свои DFF/TXD/COL/IMG на HTTPS-хостинг проекта, посчитать SHA-256 и размер, затем добавить в `client/manifest.json` запись:

```json
{
  "path": "MARCH Assets/vehicles/example.dff",
  "url": "https://your-project-cdn.example/vehicles/example.dff",
  "sha256": "64 шестнадцатеричных символа настоящего SHA-256 файла",
  "size": 12345
}
```

`path` должен находиться внутри `MARCH Assets/`. SHA-256 и `size` обязательны; не используйте фиктивные значения. При несовпадении файл не устанавливается. Обновления используют временный файл и атомарную замену; пользователь может отменить операцию.

## Ограничения текущего этапа

- Вход через `march_auth` и запуск `mtasa://127.0.0.1:22003` сохранены без изменений.
- Установщик **пока не скачивает и не настраивает MTA автоматически**; необходим официально установленный MTA 1.6.
- Простое помещение моделей в `MARCH Assets/` само по себе не подключает их к MTA. Для применения DFF/TXD/COL и IMG нужен клиентский MTA-ресурс со связкой на нужные model IDs, коллизии и серверной синхронизацией, либо отдельная согласованная схема предустановки в MTA cache. Не редактируйте `models/gta3.img` GTA:SA без особой необходимости.
- Это первый рабочий этап установщика, **не полностью автономный GTA/MTA клиент**. Перед публичным выпуском проверить сборку на Windows и интеграцию с установленным MTA.
